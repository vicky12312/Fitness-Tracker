# Fitness Tracker

A full-stack fitness tracking application built using React and Java (Spring Boot).

## Tech Stack
- Frontend: React, HTML, CSS
- Backend: Java, Spring Boot
- Database: MySQL

## Features
- Workout tracking
- Calorie monitoring
- User-based data management
- RESTful APIs

## How to Run

### Frontend
cd my-app
npm install
npm start

### Backend
Run the Spring Boot application from your IDE
